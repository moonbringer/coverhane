# Coverhane

Tarayıcıda çalışan cover stüdyosu: bir şarkı, bir tarz, bir ses seç; düzenleme anında sentezlenir. Sunucu, hesap ya da API gerekmez.

## Özellikler
- 63 telifsiz eser (26 türkü, klasikler, dünya halk ezgileri), 27 tarz, 22 ses
- Aksak ölçüler (5/8, 7/8, 9/8, 10/8) ve koma sesleri
- Radyo modu, rastgele kombinasyon, favoriler
- Kendi melodini nota yazarak ekleme ve kaydetme (tarayıcıda saklanır)
- Altı sahne teması
- MP3 / WAV indirme

## Çalıştırma
`index.html` dosyasını tarayıcıda aç. İnternet yalnızca yazı tipleri için kullanılır; olmadan da çalışır.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main`, klasör `/ (root)`.
